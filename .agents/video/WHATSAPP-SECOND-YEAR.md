# The second-year message

The copy that goes out with `orbit-reel-second-year`. Send the video and this
together: the video carries the argument, the message carries the link, because
a link inside a video is a thing nobody can tap.

## Two things that may never go in it

**No price, and no mention of ad-free.** Purchases are locked behind "coming
soon" until Play Billing is set up on a real merchant account. A message that
implies you can buy something today is a message that produces a support
conversation tomorrow.

**No feature that has never worked once on a phone.** Everything named below is
in the shipped build and has been seen working. If a feature is added to this
message, it goes in after somebody has used it, not after it compiles.

## Why it is written like this

The reference the app's owner gave is Marrow's own second-year message, and
what makes that one work is not enthusiasm — it is **specificity**. It names
the subjects, it names the exam, and it says what you get in the first line
instead of the fourth. Below is the same shape with this app's own facts, and
every number in it is one that can be checked in the build.

The one deliberate difference: it does not open with a discount, because there
is nothing to discount. It opens with the thing that is genuinely unusual
about this app — no sign-in, no payment, no trial.

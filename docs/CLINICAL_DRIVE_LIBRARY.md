## 3. Explicit Operational Instructions for Claude (How to Read & Use)

### 3.1. How Claude Must Read the PDFs

1. **Native PDF Inspection via `view_file`**:
   Claude should use the native `view_file` tool directly on any PDF path in `docs/clinical_materials/` (e.g. `view_file(AbsolutePath="/Users/sabharivarshan/.../docs/clinical_materials/Stroke_Localization.pdf")`).
   `view_file` automatically converts each page into a high-resolution screenshot image with full OCR text extraction.
   *Example*:
   ```python
   view_file(AbsolutePath="/path/to/docs/clinical_materials/ABG_Interpretation.pdf")
   ```

2. **Automated Text Extraction via Python**:
   For rapid text searching across large PDFs, Claude can run the custom extractor located at `scratch/pdf_reader.py`:
   ```bash
   python3 /path/to/scratch/pdf_reader.py /path/to/docs/clinical_materials/Surgery_VaricoseVeins.pdf
   ```

3. **Decoding Presentation / Caesar-Shifted PDFs**:
   Some PDFs exported from PowerPoint (such as `Peds_Bronchiolitis.pdf`) use custom font encodings where characters are shifted by ASCII $-3$ (e.g., `% U R Q F K L R O L W L V` $\to$ `B R O N C H I O L I T I S`). Claude can decode these with:
   ```python
   decoded = ''.join(chr(ord(c) - 3) if c.isalpha() else c for c in raw_text)
   ```

### 3.2. How Claude Can Download Any Additional File from the Google Drives

If Claude needs to fetch any additional PPTX, DOCX, or PDF directly from any of the 6 Google Drive folders, run this standard command outside the sandbox (`BypassSandbox: true`):

```bash
# Template:
curl -sL "https://drive.google.com/uc?export=download&id=<FILE_ID>" -o /path/to/destination.pdf
```

To list all files and subfolder IDs within any Google Drive folder, run:
```python
import subprocess, re, json
url = 'https://drive.google.com/drive/folders/<FOLDER_ID>'
html = subprocess.check_output(['curl', '-sL', url]).decode('utf-8', errors='ignore')
ivd = re.search(r"window\['_DRIVE_ivd'\]\s*=\s*'([^']+)'", html).group(1).encode('utf-8').decode('unicode_escape')
data = json.loads(ivd)
for item in data[0]:
    print(f"Name: {item[2]} | ID: {item[0]} | Mime: {item[3] if len(item)>3 else 'unknown'}")
```

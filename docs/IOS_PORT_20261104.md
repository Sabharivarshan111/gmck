## Cloud Mac
.github/workflows/ios-simulator.yml runs on a standard GitHub macos-15 runner on pushes to this isolated branch. It installs locked JS dependencies, typechecks and bundles the actual iOS entry point, installs Pods and compiles an unsigned Release simulator app. No signing certificates, paid cloud Mac subscription, Apple account or production deployment is used. Build-only overrides turn off ads and Google sign-in; the sample AdMob app ID is development-only.

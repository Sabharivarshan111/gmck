Original files, unmodified. Attribution, source pages and licences for each
filename are in `mobile/src/lib/examSignImages.ts` and
`mobile/src/lib/curatedExamPhotos.ts`. These details are displayed with each
photograph in the app. The three curated originals are palmar-erythema.jpg

(Alborz Fallah), each CC BY-SA 3.0. Remaining files preserve their existing

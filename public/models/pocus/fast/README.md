# Experimental source-reconstructed FAST pilot

These images are generated offline by `scripts/generate-pocus-fast-assets.py`.
They are not SVG drawings or reference photographs. BodyParts3D mesh sections
seed the acoustic phantom; PyMUST/SIMUS produces receive-channel RF which is
demodulated and delay-and-sum beamformed. Both states share the same seed and
display reference. This is a one-plane teaching experiment, not a clinically
validated RUQ acquisition or diagnostic device.

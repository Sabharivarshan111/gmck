# Video editor integration and stabilization QA — 2026-10-19

## OpenCut runtime status
- Repo already includes a **pinned Git submodule** of OpenCut Classic at `tools/video-editor/opencut-classic`.
- Official [OpenCut rewrite](https://github.com/OpenCut-app/OpenCut) README recommends Classic for currently available editing; Classic is archived.
- `start-opencut.sh` has **NOT** been successfully smoke-tested in this environment. GitHub DNS resolution and npm registry lookup failed, and Bun is not installed. The attached videos were processed with FFmpeg/OpenCV, **not inside OpenCut**. Do not claim otherwise.
- Source files and exported footage are private local attachments and **must not** be committed to this public repository.

## Motion QA (background optical flow)
Measured in 360×640 reference coordinates using masked KLT background optical-flow, then 12-frame Gaussian high-pass displacement RMS.

| Clip | Original RMS | Earlier edit | Evaluated master | Finding |
|---|---:|---:|---:|---|
| Garden | 2.964px | 1.772px | 1.772px | Previous stabilized master already ~40% below original; retained to avoid extra lossy re-encode |
| Street | 4.483px | 4.346px | 3.785px | Earlier result ~3% improvement; revised background-only stabilization ~16% below original |

This is a proxy for jitter—not proof of perfect stabilization. It is affected by intended pans and mask selection. The revised street clip corrects background motion in approximately 99.5% of frames and caps offsets at 11px horizontal and 15px vertical, with a fixed crop. Remaining blur, rolling-shutter distortion and clipped lamps cannot be reliably reconstructed.

## Export QA
Both evaluated masters decode with FFmpeg exit status 0 and have H.264, 1080×1920, 30fps. Garden has 202 frames, street 590. The street delivery is **upscaled from 360p**; higher bitrate or resolution does not restore source detail. Neither source had audio.

## What would be required to verify real OpenCut execution
On a machine with network access and Bun installed:
```bash
git clone --recurse-submodules https://github.com/Sabharivarshan111/gmck.git
cd gmck
bash tools/video-editor/start-opencut.sh
```
Open the resulting localhost editor, import the private originals from local disk and verify timeline and output in the GUI. Do not substitute a subprocess render via FFmpeg for a verified OpenCut export.
